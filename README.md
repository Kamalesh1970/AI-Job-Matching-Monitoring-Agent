# AI Job-Matching & Monitoring Agent (Phase 1, Phase 2 & Phase 3)

A reliable, modular job ingestion, deduplication, resume-to-job matching, and Telegram notification pipeline designed for an AI & Data Science candidate seeking relevant Machine Learning, Data Science, and Software Development positions.

> **Disclaimer**: The match score generated by this system is a **ranking signal**, NOT a probability of hiring or interview success.  
> **Notice**: *The Telegram integration sends job recommendations for human review. It does not automatically apply to jobs.*

---

## 1. Project Purpose & System Pipeline

The long-term pipeline of the AI Job-Matching & Monitoring Agent encompasses:
1. **Source Fetchers** (Phase 1 - Adzuna API)
2. **Dedup & SQLite Storage** (Phase 1 - Exact & Fingerprint deduplication)
3. **Resume & Job Matching Engine** (Phase 2 - Semantic embeddings, Skill extraction, Rule filtering)
4. **Telegram Daily Job Digest** (Phase 3 - Threshold filtering, Notification deduplication, Telegram delivery)

---

## 2. Phase Scope & Methodology

### Phase 1: Ingestion & Deduplication
- Fetches jobs via Adzuna API with search keywords.
- Normalizes titles, locations, descriptions, and salary currency.
- Generates SHA-256 content fingerprints for deduplication in SQLite (`data/jobs.db`).

### Phase 2: Resume & Job Matching Engine
- **Semantic Embeddings**: Uses `all-MiniLM-L6-v2` via `sentence-transformers` for cosine similarity calculation.
- **Skill Overlap**: Regex boundary matching against canonical tech skills.
- **Rule Filtering**: Evaluates experience level (filtering senior/lead roles) and location preferences.
- **Weighted Match Score (0 - 100)**: 50% Semantic + 30% Skill + 20% Rule compatibility.

### Phase 3: Telegram Daily Job Digest
- **Decoupled Notification Service**: `TelegramNotifier` handles HTTPS requests to the official Telegram Bot API (`sendMessage`).
- **Minimum Score Threshold**: Notifies only matches meeting or exceeding `TELEGRAM_MIN_MATCH_SCORE` (default 70.0). Filtered roles are ignored.
- **Message Formatting & Chunking**: Formats clean job cards and chunks messages under character limits while strictly preserving job card boundaries.
- **Notification Deduplication & Failure Resilience**:
  - Tracks sent notifications in SQLite (`job_notifications` table).
  - Records notification history **only after** Telegram API confirms successful delivery.
  - If a message chunk fails to deliver, included jobs remain unnotified and eligible for future retry digests.
- **Security**: Bot token is never printed, logged, or saved to SQLite.

## 4. Setup & Environment Variables (.env)

Copy `.env.example` to `.env` and fill in credentials:

```ini
ADZUNA_APP_ID=your_app_id
ADZUNA_APP_KEY=your_app_key
ADZUNA_COUNTRY=in
ADZUNA_RESULTS_PER_PAGE=20
ADZUNA_MAX_PAGES=2

RESUME_PATH=data/resume/base_resume.txt
EMBEDDING_MODEL=all-MiniLM-L6-v2
SEMANTIC_WEIGHT=0.50
SKILL_WEIGHT=0.30
RULE_WEIGHT=0.20
MIN_MATCH_SCORE=60
PREFERRED_LOCATIONS=Coimbatore,Chennai,Bangalore,Bengaluru,Hyderabad,Pune,Remote,India

TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=987654321
TELEGRAM_MIN_MATCH_SCORE=70
TELEGRAM_MAX_JOBS_PER_DIGEST=10
TELEGRAM_ENABLED=true
SEND_EMPTY_DIGEST=false
```

### Telegram Bot Setup Instructions:
1. Open Telegram and search for `@BotFather`.
2. Send `/newbot` and follow prompt instructions to generate a bot token.
3. Start a chat with your bot.
4. Obtain your Chat ID (e.g., using `@userinfobot` or visiting `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`).
5. Set `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` in `.env`.

## 5. Running the Application

### Full Pipeline (Ingestion + Resume Matching)
```bash
python3 -m app.main
```

### Phase 3 Telegram Daily Job Digest Mode
```bash
python3 -m app.main --digest
```

### Custom Execution Modes
- Skip ingestion (match & digest existing stored jobs):
  ```bash
  python3 -m app.main --skip-ingestion --digest
  ```
