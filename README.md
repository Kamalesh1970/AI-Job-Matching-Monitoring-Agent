# AI Job-Matching & Monitoring Agent (Phases 1–7)

A reliable, modular job ingestion, deduplication, resume-to-job matching, Telegram digest, scheduled monitoring daemon, multi-source Yellow-tier ingestion engine, Gmail API email alert ingestion system, and Gemini API-powered resume tailoring with mandatory human review.

> **Disclaimer**: The match score generated by this system is a **ranking signal**, NOT a probability of hiring or interview success.  
> **Notice**: *The Telegram integration sends job recommendations for human review. It does not automatically apply to jobs.*  
> **Operational Note**: *A healthy scheduler process does not necessarily mean the job pipeline is healthy. Health is determined from recent successful pipeline completion.*
> **Responsible Use Note**: *"Internshala integration is designed for conservative personal-scale monitoring and does not attempt to bypass anti-bot protections."*
> **Security & Privacy Note**: *"Gmail API access strictly uses read-only OAuth (`https://www.googleapis.com/auth/gmail.readonly`). Gemini API resume tailoring operates on an explicit opt-in basis (`LLM_ENABLED=false` by default). When `LLM_ENABLED=true`, master resume and job content are sent to Google Gemini for tailoring. Secret keys, OAuth tokens, and credentials are NEVER sent to Gemini, printed, logged, or saved in version control."*
> **No Auto-Application Policy**: *"This system generates tailored resume drafts for human review. It NEVER performs automatic job applications, browser automation, or automatic resume submissions."*

## 1. Project Purpose & System Pipeline

The long-term pipeline of the AI Job-Matching & Monitoring Agent encompasses:
1. **Source Fetchers** (Phase 1 - Adzuna API, Phase 5 - Internshala Yellow-tier source, Phase 6 - Gmail API LinkedIn & Indeed alert ingestion)
2. **Dedup & SQLite Storage** (Phases 1, 5, 6 & 7 - Exact & Fingerprint deduplication, tailored resume draft tracking)
3. **Resume & Job Matching Engine** (Phase 2 - Semantic embeddings, Skill extraction, Rule filtering)
4. **Telegram Daily Job Digest** (Phase 3 - Threshold filtering, Notification deduplication, Telegram delivery)
5. **Scheduler & Reliability Infrastructure** (Phase 4 - APScheduler daemon, Heartbeat monitoring, Stale health alerts, Failure isolation)
6. **Multi-Source Yellow-Tier Expansion** (Phase 5 - Internshala HTML parsing, rate-limiting jitter, configurable intervals, per-source status tracking)
7. **Gmail API Alert Email Ingestion** (Phase 6 - Read-only OAuth 2.0 access, base64url MIME decoding, LinkedIn & Indeed HTML email parsing, deduplication)
8. **Gemini Resume Tailoring & Human Review** (Phase 7 - `LLMProvider` abstraction, `GeminiProvider` using official `google-genai` SDK, Pydantic structured output, `ResumeProfile` source of truth, `TruthValidator` deterministic validation, SQLite draft versioning, interactive CLI review, and Markdown export)

## 2. Phase Scope & Architecture

### Phase 1: Ingestion & Deduplication (Adzuna)
- Fetches jobs via Adzuna API with search keywords.
- Normalizes titles, locations, descriptions, and salary currency.
- Generates SHA-256 content fingerprints for deduplication in SQLite (`data/jobs.db`).

### Phase 2: Resume & Job Matching Engine
- **Semantic Embeddings**: Uses `all-MiniLM-L6-v2` via `sentence-transformers` for cosine similarity calculation.
- **Skill Overlap**: Regex boundary matching against canonical tech skills.
- **Rule Filtering**: Evaluates experience level (filtering senior/lead roles) and location preferences.
- **Weighted Match Score (0 - 100)**: 50% Semantic + 30% Skill + 20% Rule compatibility.

### Phase 3: Telegram Daily Job Digest
- **Decoupled Notification Service**: `TelegramNotifier` handles HTTPS requests to the official Telegram Bot API (`sendMessage`).
- **Minimum Score Threshold**: Notifies only matches meeting or exceeding `TELEGRAM_MIN_MATCH_SCORE` (default 70.0).
- **Message Formatting & Chunking**: Formats clean job cards and chunks messages under character limits while strictly preserving job card boundaries.
- **Notification Deduplication & Failure Resilience**: Tracks sent notifications in SQLite (`job_notifications` table). Records notifications **only after** delivery confirmation.

### Phase 4: Scheduler, Reliability & Heartbeat Monitoring
- **APScheduler Daemon**: `PipelineScheduler` runs periodic monitoring cycles using background interval triggers.
- **Overlap & Misfire Protection**: Configured with `max_instances=1`, `coalesce=True`, and `misfire_grace_time=900` to prevent duplicate concurrent runs.
- **Failure Isolation**: Component failures (Adzuna network errors, missing resume, or Telegram HTTP errors) are caught, logged, and isolated.
- **Pipeline Run Tracking**: Every execution is recorded in SQLite (`pipeline_runs` table) with status (`SUCCESS`, `PARTIAL_FAILURE`, `FAILED`), metrics, duration, and error details.
- **Heartbeat & Health Evaluation**:
  - `HEALTHY`: Last successful run completed within `HEARTBEAT_TIMEOUT_MINUTES`.
  - `STALE`: Time since last successful run exceeds `HEARTBEAT_TIMEOUT_MINUTES`.
  - `FAILED`: Last run suffered a critical failure.
- **Deduplicated Health Alerts**: Dispatches a Telegram operational alert upon transitioning into a `STALE` state, recorded in `health_alerts` to prevent notification spam.

### Phase 5: Internshala Yellow-Tier Source Integration
- Implements `InternshalaJobSource(BaseJobSource)` returning standard internal `Job` dataclass objects seamlessly into the pipeline.
- Uses `requests` and `BeautifulSoup4` with rate-limiting jitter between requests.
- Halts execution gracefully on HTTP 403, 429, 503, or anti-bot challenges while preserving overall pipeline stability.

### Phase 6: Gmail API + LinkedIn & Indeed Alert Email Ingestion
- Ingests native job-alert emails sent directly to Gmail by LinkedIn and Indeed.
- Uses read-only OAuth 2.0 (`https://www.googleapis.com/auth/gmail.readonly`).
- Decodes base64url encoded MIME bodies and parses job details without scraping external sites.

### Phase 7: Gemini API LLM Resume Tailoring + Human Review
- **Provider Abstraction**: Abstract `LLMProvider` interface wrapping `GeminiProvider` (`google-genai` Python SDK) and `OpenAIProvider`.
- **Structured Output**: Uses Pydantic schema `TailoredResume` (summary, skills, experience, projects, education, certifications, changes, warnings) for response validation.
- **Master Resume Source of Truth**: `ResumeProfile` acts as the single factual source of truth. The LLM is strictly prohibited from inventing skills, experience, metrics, employment, education, certifications, or project results.
- **Deterministic Truth Validator**: `TruthValidator` checks generated resumes post-generation. Unsubstantiated claims cause status = `INVALID`.
- **Match Score Threshold**: Only invokes Gemini when `match_score >= LLM_MATCH_THRESHOLD` (default 0.75 / 75.0%). Otherwise assigns status `SKIPPED_LOW_MATCH`.
- **SQLite Persistence & Versioning**: Drafts stored in `tailored_resumes` table with states (`DRAFT`, `VALIDATED`, `APPROVED`, `REJECTED`, `INVALID`, `SKIPPED_LOW_MATCH`, `FAILED`). Supports multiple versions per job.
- **Human Review CLI**: Interactive `--review-resume <draft_id>` workflow requiring explicit human approval (`[A] Approve`, `[R] Reject`, `[V] View validation details`, `[C] Cancel`). `INVALID` drafts CANNOT be approved.
- **Markdown Export**: Only `APPROVED` drafts can be exported as Markdown via `--export-resume <draft_id>`.

## 3. Configuration Parameters (.env)

Set environment variables in `.env`:

```env
# Phase 1: Adzuna API Credentials
ADZUNA_APP_ID=your_app_id_here
ADZUNA_APP_KEY=your_app_key_here
ADZUNA_COUNTRY=in
ADZUNA_RESULTS_PER_PAGE=20
ADZUNA_MAX_PAGES=2

# Phase 5: Internshala Yellow-Tier Configuration

INTERNSHALA_REQUEST_DELAY_MIN=2
INTERNSHALA_REQUEST_DELAY_MAX=5
INTERNSHALA_MAX_PAGES=3

# Phase 6: Gmail API Configuration (Disabled by default)
GMAIL_ENABLED=false
GMAIL_CREDENTIALS_PATH=credentials.json
GMAIL_TOKEN_PATH=token.json
GMAIL_QUERY_LIMIT=50
GMAIL_LOOKBACK_DAYS=2

# Phase 7: Gemini API Resume Tailoring Configuration (Disabled by default)

GEMINI_MODEL=gemini-2.5-flash
LLM_TEMPERATURE=0.2
LLM_MATCH_THRESHOLD=0.75

# Database & Resume Settings
DB_PATH=data/jobs.db
RESUME_PATH=data/resume/base_resume.txt
EMBEDDING_MODEL=all-MiniLM-L6-v2

# Phase 2: Matching Weights (Must sum to 1.0)
SEMANTIC_WEIGHT=0.50
SKILL_WEIGHT=0.30
RULE_WEIGHT=0.20
MIN_MATCH_SCORE=60.0

# Phase 3: Telegram Bot Credentials
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHAT_ID=987654321
TELEGRAM_MIN_MATCH_SCORE=70.0
TELEGRAM_MAX_JOBS_PER_DIGEST=10
TELEGRAM_ENABLED=true

# Phase 4: Scheduler & Heartbeat
SCHEDULER_ENABLED=true
SCHEDULER_INTERVAL_MINUTES=60
HEARTBEAT_TIMEOUT_MINUTES=180
RUN_ON_STARTUP=true
```

## 4. Running the Application

### Scheduled Monitoring Daemon (Phase 4 Mode)
Runs APScheduler as a long-running background daemon:
```bash
python3 -m app.main --scheduler
```

### Single Pipeline Run (Manual / Cron Mode)
Executes one complete monitoring cycle (Ingestion -> Matching -> Tailoring -> Digest -> Health check) and exits:
```bash
python3 -m app.main --run-once
```

### Trigger Resume Tailoring Manually
Generates a tailored resume draft for a specific job ID:
```bash
python3 -m app.main --tailor-resume 42
```

### Interactive Human Review CLI
Interactively review, inspect validation report, and approve/reject a tailored resume draft:
```bash
python3 -m app.main --review-resume 1
```

### Export Approved Resume to Markdown
Exports an `APPROVED` tailored resume draft as a Markdown document:
```bash
python3 -m app.main --export-resume 1
```

### Safe Gmail Ingestion Test
Executes a dry-run test of LinkedIn and Indeed alert email ingestion:
```bash
python3 -m app.main --gmail-test
```
